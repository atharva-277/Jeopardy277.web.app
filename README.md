# Jeopardy

A simple jeopardy/trivia game which I coded in JavaScript.

# Features
* Board
  * Contains 5 columns with 5 rows
  * Categories: Movies, Geography, General Knowledge, Riddles and Food
  * Money Amounts: $100, $200, $300, $400, $500
  * Interactive buttons leading to questions
* Question Page
  * Displays questions and answers
  * Removes board cell from board after answering
* Super Question Page
  * Accessed via clicking "BOARD" at top of Board Page
  * Two categories with two questions each
  * No money amount, play with house rules!

# How It Works
DOM and JS makes it a simple site with buttons hiding and display certain elements
